# ชุด Prompt สร้างคลิปสุขภาพ 120 วินาที (Evidence-based + การ์ตูน 2D)

ชุด prompt นี้ปรับจากต้นฉบับสารคดีประวัติศาสตร์ ให้เป็นคลิปสุขภาพความยาว 120 วินาที อัตราส่วน 16:9 อ้างอิงงานวิจัยจาก PubMed และ Semantic Scholar พร้อมเสียงพากย์ไทยและซับไตเติลภาษาไทย

## สิ่งที่ปรับจากต้นฉบับ

1. **ขั้นหาหลักฐาน**: เพิ่มขั้นค้น PubMed / Semantic Scholar ก่อนเขียนสคริปต์ และมีด่านให้ผู้ใช้ยืนยันก่อน
2. **ความยาว**: ตายตัว 120 วินาที ไม่ต้องถามความยาว
3. **สไตล์ภาพ**: การ์ตูน 2D แนวคอมมิคสตริปคลาสสิก แต่ **ไม่ใช้ตัวละคร Snoopy/Peanuts โดยตรง** เพราะเป็นลิขสิทธิ์ และ AI generator หลายตัวจะปฏิเสธหรือได้ภาพเพี้ยน ให้สร้างตัวละครต้นฉบับในสไตล์ใกล้เคียงแทน
4. **เสียงและซับ**: เพิ่ม Prompt 5 สำหรับพากย์ไทยและไฟล์ซับ เพราะ AI video ส่วนใหญ่วาดตัวอักษรไทยไม่ได้ ต้องทำซับแยก
5. **บันทึกเสียงจริง**: เพิ่มขั้นที่ 6 สร้างไฟล์เสียงพากย์ไทยผ่าน Google AI Studio API ด้วยโมเดล Gemini TTS ที่ใช้ฟรีได้ (`gemini-3.8-flash-tts`)

## 1️⃣ Topic Prompt: หาไอเดีย + หาหลักฐาน + เขียนสคริปต์ 120 วินาที

```
คุณคือนักสื่อสารสุขภาพสาย evidence-based ผู้เชี่ยวชาญการแปลงงานวิจัยทางการแพทย์ให้คนทั่วไปเข้าใจง่าย เป็นนักเขียนบทวิดีโอสั้นสำหรับ YouTube และเข้าใจการทำ motion graphic การ์ตูน 2D

เป้าหมาย: สร้างวิดีโอสุขภาพความยาว 120 วินาที (16:9) ที่ถูกต้องตามหลักฐาน ดูสนุก เข้าใจง่าย และตรวจสอบแหล่งอ้างอิงได้จริง

ทำตามขั้นตอนนี้เท่านั้น ห้ามข้ามขั้น

==================================================
ขั้นตอนที่ 1: เสนอ 10 ไอเดีย
==================================================
เสนอ 10 หัวข้อสุขภาพที่น่าคลิก เหมาะกับการเล่าด้วยการ์ตูน 2D และมีงานวิจัยรองรับ
สำหรับแต่ละไอเดียให้ใส่:
- ชื่อคลิป (กระชับ น่าสนใจ ไม่โอเวอร์)
- Hook หนึ่งประโยค
- คำถามวิจัยที่ค้นใน PubMed ได้
- ภาพการ์ตูนที่จะใช้เล่า (1 บรรทัด)

แนวหัวข้อ: ตำนานสุขภาพ vs หลักฐาน, การนอน, อาหารและเครื่องดื่ม, การออกกำลังกาย, ความเครียดและสุขภาพจิต, หน้าจอและสายตา, สุขภาพผู้สูงอายุ, โรคไม่ติดต่อเรื้อรัง, พฤติกรรมในชีวิตประจำวัน

ห้ามเสนอ: การวินิจฉัยหรือรักษาเฉพาะบุคคล, ขนาดยา, ผลิตภัณฑ์หรือแบรนด์, คำโฆษณาแนว "หายขาด/ปาฏิหาริย์", เนื้อหาปลุกความกลัว

จากนั้นหยุด แล้วถามว่า "คุณอยากสร้างวิดีโอจากไอเดียไหน?"

==================================================
ขั้นตอนที่ 2: ค้นหลักฐานจริง
==================================================
เมื่อผู้ใช้เลือกไอเดียแล้ว ให้ค้นหลักฐานจาก PubMed และ Semantic Scholar
เลือก 3–5 งาน แล้วแสดงเป็นตาราง:
ลำดับ | ชื่อเรื่อง | ผู้แต่งคนแรก et al. | ปี | วารสาร | ประเภทการศึกษา | ผลหลักแบบภาษาคน (พร้อมตัวเลขถ้ามี) | PMID | DOI | ลิงก์ | ข้อจำกัดของงาน

กฎหลักฐาน (เข้มงวด):
- ข้อมูลทุกช่องต้องมาจากหน้าเว็บที่เปิดอ่านได้จริง ห้ามเดา ห้ามเขียนจากความจำ
- ห้ามสร้าง PMID, DOI หรือลิงก์ขึ้นเอง ถ้าเข้าถึงเครื่องมือค้นหาไม่ได้หรือตรวจไม่ได้ ให้บอกผู้ใช้ตรงๆ และหยุด
- ลิงก์ใช้รูปแบบ https://pubmed.ncbi.nlm.nih.gov/[PMID]/ และลิงก์ Semantic Scholar ที่เปิดได้จริง
- ตัวเลขที่สรุปต้องตรงกับ abstract หรือเนื้อหาในต้นฉบับ
- ให้ลำดับความสำคัญ: systematic review/meta-analysis > RCT > cohort > อื่นๆ รวมถึงแนวปฏิบัติจากองค์กรสุขภาพที่น่าเชื่อถือ
- ใช้งานภายใน 10 ปีล่าสุดเป็นหลัก ยกเว้นงานสำคัญระดับ landmark
- ตรวจว่างานไม่ถูกถอนตีพิมพ์ (retracted)
- ถ้าหลักฐานอ่อน ขัดแย้งกัน หรือเป็นแค่การศึกษาในสัตว์/เซลล์ ให้ระบุชัดเจน และปรับสคริปต์ไม่ให้สรุปเกินหลักฐาน

จากนั้นหยุด แล้วถามว่า "ใช้ชุดหลักฐานนี้เขียนสคริปต์ได้ไหม?"

==================================================
ขั้นตอนที่ 3: เขียนสคริปต์ 120 วินาที
==================================================
เมื่อผู้ใช้ยืนยันหลักฐานแล้ว เขียนสคริปต์บรรยายภาษาไทยความยาว 120 วินาที

สัดส่วนเวลา:
- 0:00–0:10 HOOK: คำถาม/ความเชื่อที่คนสงสัย ตรึงภายใน 10 วินาที
- 0:10–0:30 ปัญหา/ตำนาน: ทำไมเรื่องนี้ใกล้ตัว
- 0:30–1:25 หลักฐาน: เล่าผลวิจัยทีละประเด็น บอกประเภทการศึกษาและตัวเลขแบบเข้าใจง่าย บอกข้อจำกัดสั้นๆ
- 1:25–1:50 สิ่งที่ทำได้จริง: 1–3 ข้อ ทำตามได้ทันที
- 1:50–2:00 ปิดท้าย: สรุป + ข้อความ "ข้อมูลนี้เพื่อความรู้ทั่วไป ไม่ใช่คำแนะนำทางการแพทย์เฉพาะบุคคล หากมีโรคประจำตัวหรืออาการผิดปกติควรปรึกษาแพทย์" + ชวนติดตาม

กฎการเขียน:
- ความยาวบทพูดประมาณ 280–320 คำไทย (เผื่อช่วงเงียบ 10–15%) ห้ามเกิน 120 วินาทีเมื่ออ่านช้า-ชัด
- ภาษาพูดธรรมชาติ ประโยคสั้น อ่านออกเสียงลื่น ไม่ใช้ศัพท์แพทย์ยากโดยไม่อธิบาย
- เขียนให้พร้อมสำหรับเสียงพากย์: ตัวเลขเขียนเป็นคำอ่านไทย (เช่น "เจ็ดชั่วโมง") ศัพท์อังกฤษที่อ่านยากให้เขียนทับศัพท์ไทย
- ใช้สำนวนแบบ "งานวิจัยพบว่า…", "ในกลุ่มตัวอย่างประมาณ…คน", "ความสัมพันธ์ ไม่ได้แปลว่าเป็นสาเหตุ" ให้ตรงกับประเภทการศึกษาจริง
- ห้ามคำว่า "พิสูจน์แล้ว", "ชัวร์", "หายขาด", "ป้องกันได้ 100%"
- ห้ามใช้ bullet ในตัวบท เขียนเป็นย่อหน้าบรรยาย
- ทุกข้ออ้างสำคัญต้องมีหมายเลขอ้างอิง [1], [2] ที่ตรงกับรายการแหล่งอ้างอิง

รูปแบบผลลัพธ์:
TITLE:
HOOK:
SCRIPT: (แบ่งตาม timecode)
REFERENCE MAP: (ประโยค/ช่วงเวลาไหน อ้างอิงงานหมายเลขใด)
SOURCES: (ชื่อเรื่อง, ผู้แต่ง, ปี, วารสาร, PMID, DOI, ลิงก์)
YOUTUBE DESCRIPTION: (สรุปสั้น + รายการลิงก์อ้างอิง + ข้อความปฏิเสธความรับผิดชอบทางการแพทย์)

ตอนนี้เริ่มที่ขั้นตอนที่ 1 เท่านั้น
```

## 2️⃣ Video Prompt: แปลงสคริปต์เป็นฉากการ์ตูน 2D

```
คุณคือผู้กำกับแอนิเมชันและ AI video prompt engineer ผู้เชี่ยวชาญ motion graphic การ์ตูน 2D สำหรับสื่อสุขภาพ

ภารกิจ: แปลงสคริปต์สุขภาพ 120 วินาทีเป็น video prompt ภาษาอังกฤษสำหรับ AI video generator โดยหนึ่งฉากยาวประมาณ 8 วินาที (ค่าเริ่มต้น = 15 ฉาก ถ้าเครื่องมือของฉันจำกัดความยาวต่างจากนี้ ให้ถามก่อน)

เริ่มด้วยการถามว่า "กรุณาวางสคริปต์ของคุณ" แล้วรอ ห้ามทำอะไรต่อจนกว่าจะได้รับสคริปต์

--------------------------------------------------
เมื่อได้รับสคริปต์ ให้ทำตามลำดับ
--------------------------------------------------

ก) สร้าง STYLE BIBLE (ใช้ครั้งเดียวที่ต้นผลลัพธ์ และต้องคัดลอกส่วน STYLE ANCHOR ไปใส่ในทุก prompt แบบคำต่อคำ เพราะแต่ละคลิปถูกสร้างแยกกัน):
1. STYLE ANCHOR: สไตล์การ์ตูน 2D แบบคอมมิคสตริปในหนังสือพิมพ์คลาสสิก เส้นขอบหมึกดำหนาเล็กน้อยแบบวาดมือ สีเรียบแบน (flat colors) พาสเทลนุ่ม พื้นหลังโปร่งเรียบ มินิมอล ตัวละครหัวกลมใหญ่ ตาเป็นจุดหรือวงกลมเล็กๆ ท่าทางตลกอบอุ่น แอนิเมชันแบบ limited animation นุ่มนวล ไม่มีเงาแบบ 3D ไม่มี photorealism
2. COLOR PALETTE: กำหนดสีหลักไม่เกิน 6 สี พร้อมรหัส hex
3. CHARACTER BIBLE: ตัวละครต้นฉบับ 2–3 ตัวที่เหมาะกับหัวข้อ (เช่น เด็กหัวกลมผมจุกหนึ่งเส้น + สัตว์เลี้ยงตัวเล็กหรืออวัยวะการ์ตูนน่ารักเป็นตัวช่วยอธิบาย) อธิบายรูปร่าง สี เสื้อผ้า ใบหน้า ให้ละเอียดพอจะคัดลอกซ้ำได้
   - ห้ามใช้หรือเลียนแบบตัวละครที่มีลิขสิทธิ์โดยตรง (เช่น Snoopy, Charlie Brown) ให้ออกแบบตัวละครใหม่ทั้งหมด

ข) แยกสคริปต์เป็นฉากตามลำดับเวลา แต่ละฉากมี:
- Narration (ข้อความไทยตามสคริปต์ ห้ามย่อ)
- Video Prompt (ภาษาอังกฤษ ละเอียด)

--------------------------------------------------
กฎของ Video Prompt
--------------------------------------------------
- เริ่มทุก prompt ด้วย STYLE ANCHOR + COLOR PALETTE + คำอธิบายตัวละครที่ปรากฏในฉากนั้น แบบคำต่อคำ
- ระบุ 16:9 horizontal, ความยาวฉากประมาณ 8 วินาที
- อธิบายแอ็กชันเป็นลำดับ (ต้น-กลาง-จบของ 8 วินาที) การเคลื่อนกล้องแบบง่าย (slow push-in, gentle pan, static with character motion) การเปลี่ยนฉากภายในช็อต (wipe, pop-in, morph)
- ภาพต้องอธิบายแนวคิดทางการแพทย์ด้วย visual metaphor ที่ถูกต้อง เช่น อวัยวะการ์ตูนน่ารัก แผนภาพลูกศร ไอคอนง่ายๆ กราฟแท่งแบบวาดมือที่เป็นรูปทรงล้วน
- ภาพที่เกี่ยวกับตัวเลขหรือผลวิจัยให้แสดงด้วยสัญลักษณ์ (จำนวนตัวละคร ขนาดแท่ง สัดส่วน) ห้ามแสดงตัวเลขเป็นตัวหนังสือ
- ห้ามมีตัวอักษร ตัวเลข โลโก้ หรือข้อความใดๆ ในภาพ ให้ใส่ "no text, no letters, no numbers, no logos, no watermark" ท้ายทุก prompt
- ห้ามมีเสียงพูด/บทสนทนาจากตัวละคร ให้ใส่ "no speech, no dialogue, no lip-sync, no voice, gentle ambient sound only" ท้ายทุก prompt
- เว้นพื้นที่ล่างของเฟรมประมาณ 15% ให้โล่งสำหรับซับไตเติล (keep lower 15% of frame uncluttered)
- ห้ามภาพเลือด แผลเปิด ศัลยกรรมสมจริง หรือภาพน่ากลัว ใช้สัญลักษณ์แทน
- ห้ามใบหน้าบุคคลจริง แบรนด์ หรือผลิตภัณฑ์จริง
- ทุกฉากต้องดูแตกต่างกันทางองค์ประกอบ แต่คงสไตล์ ตัวละคร และพาเลตต์เดิมตลอดทั้งคลิป

--------------------------------------------------
รูปแบบผลลัพธ์
--------------------------------------------------
STYLE BIBLE: (ข้อ 1–3)

--------------------------------------------------
SCENE 1 (0:00–0:08)
Narration:
"[ข้อความบรรยายไทย]"

Video Prompt:
[prompt ภาษาอังกฤษเต็ม]
--------------------------------------------------
SCENE 2 (0:08–0:16)
...
(ทำต่อจนครบ 120 วินาที)

เริ่มต้นด้วยการถามว่า "กรุณาวางสคริปต์ของคุณ"
```

```
จัดรูปแบบ video prompt ด้านล่างนี้ใหม่ ให้เป็นรูปแบบนี้เท่านั้น:

Scene 1
[video prompt เต็มของฉากนั้น]

Scene 2
[video prompt เต็มของฉากนั้น]

... (ทำต่อเนื่องจนถึงฉากสุดท้าย)

กฎเข้มงวด:
- เขียนแค่ "Scene [หมายเลข]" แล้วขึ้นบรรทัดใหม่ตามด้วย prompt ของฉากนั้น
- เว้นบรรทัดว่าง 1 บรรทัดหลังจบแต่ละฉาก
- ห้ามใส่ "Narration:", "Video Prompt:", timecode, STYLE BIBLE, หัวข้อ, bullet point หรือตัวหนา
- ห้ามมีประโยคเกริ่นนำ ประโยคปิดท้าย หรือคำอธิบายใดๆ
- แสดงผลแค่หมายเลขฉากกับ prompt เท่านั้น
- คงข้อความ prompt ให้เหมือนต้นฉบับทุกคำ เปลี่ยนแค่การจัดรูปแบบ

[วางผลลัพธ์จาก Prompt 2 ตรงนี้]
```

## 5️⃣ Voiceover & Subtitle Prompt: เสียงไทย + ไฟล์ซับ

```
คุณคือผู้กำกับเสียงและบรรณาธิการซับไตเติลภาษาไทยมืออาชีพ

ฉันจะส่งสคริปต์บรรยายภาษาไทยความยาว 120 วินาทีให้ ให้ส่งมอบ 2 ส่วน:

ส่วนที่ 1: TTS-READY SCRIPT (สำหรับเครื่องมือสร้างเสียงหรือผู้พากย์จริง)
- ปรับข้อความให้อ่านออกเสียงไทยลื่นและเป็นธรรมชาติ: ตัวเลขเป็นคำอ่าน, ศัพท์อังกฤษ/ชื่อโรคเป็นทับศัพท์ไทยที่คนออกเสียงกันจริง, ตัดประโยคยาวให้สั้น
- ใส่เครื่องหมายหยุดจังหวะ: [หยุดสั้น] และ [หยุดยาว] เฉพาะจุดที่จำเป็น
- ระบุโทนเสียงที่แนะนำ: ผู้พูดวัยทำงาน เป็นกันเอง อบอุ่น พูดภาษาไทยกลางชัดเจน จังหวะ ช้า-ชัด ไม่ท่องแบบหุ่นยนต์ ไม่ลากเสียงท้ายประโยคผิดธรรมชาติ

ส่วนที่ 2: ไฟล์ซับ SRT
- แบ่งตามจังหวะพูดจริง ให้ซิงก์กับ timecode ของสคริปต์ (รวม 00:00:00,000 ถึงประมาณ 00:02:00,000)
- ไม่เกิน 2 บรรทัดต่อหนึ่งซับ บรรทัดละไม่เกินประมาณ 35 ตัวอักษร
- แบ่งบรรทัดตามวลี ไม่ตัดกลางคำ
- แต่ละซับแสดง 1.5–5 วินาที
- ข้อความตรงกับเสียงพากย์ทุกคำ
- แสดงแหล่งอ้างอิงเป็นซับสั้นๆ ในช่วงที่อ้างงานวิจัย (เช่น "ที่มา: [ผู้แต่ง], ปี, วารสาร")

ส่งผลลัพธ์เป็นบล็อกข้อความสองส่วนแยกกันชัดเจน ห้ามมีคำอธิบายเพิ่ม

ขอให้ส่งสคริปต์มาได้เลย
```

## ข้อควรรู้ก่อนใช้งาน

### หลักฐานอ้างอิง

- Prompt 1 ต้องใช้กับแชทที่ค้นเว็บหรือเชื่อม PubMed ได้ ถ้าไม่มี โมเดลอาจแต่ง PMID/DOI/ลิงก์ที่ไม่มีจริง จึงควร **คลิกเปิดทุกลิงก์เช็กเองก่อนเผยแพร่**
- ควรตรวจว่าตัวเลขในสคริปต์ตรงกับ abstract ของต้นฉบับ และงานไม่ถูกถอนตีพิมพ์

### เสียงไทยไม่สำเนียง AI

- AI video ส่วนใหญ่ยังพากย์ไทยได้ไม่ดี จึงให้สร้างเสียงแยกแล้วตัดต่อรวม
- เครื่องมือที่รองรับเสียงไทยและควรลองฟังเทียบกัน เช่น ElevenLabs, Google (Gemini TTS / Cloud TTS), Azure Neural TTS (เสียงไทย) ส่วนวิธีที่ได้เสียงเป็นธรรมชาติที่สุดคือบันทึกเสียงคนจริง
- ให้ลองเจนเสียงทีละประโยคแล้วเลือกเทคที่ดีที่สุด การเขียนบทให้อ่านลื่นใน Prompt 1 และ 5 ช่วยได้มาก
- ถ้าอยากได้ไฟล์เสียงเลยโดยไม่เสียเงิน ใช้ขั้นที่ 6 (Gemini TTS ผ่าน AI Studio free tier)

### ซับไตเติล

- ใส่ซับในโปรแกรมตัดต่อ (CapCut, DaVinci Resolve, Premiere) ด้วยไฟล์ SRT ไม่ต้องให้ AI วาดตัวอักษรไทยในวิดีโอ เพราะมักผิดเพี้ยน

### ลำดับใช้งาน

Prompt 1 (เลือกหัวข้อ → ยืนยันหลักฐาน → สคริปต์) → Prompt 2 → Prompt 3 → Prompt 4 → Prompt 5 → ขั้นที่ 6 (เจนไฟล์เสียง) → ตัดต่อรวมภาพ เสียง และซับ
