# เขียนบทพากย์ไทยให้ไม่ฟังเป็น AI

โมเดล TTS อ่านข้อความตามตัวอักษร (verbatim) ดังนั้นเสียงจะธรรมชาติได้ก็ต่อเมื่อ **บทเป็นภาษาพูด** ปรับที่บทก่อนปรับที่เสียง

## 1. สำนวนที่ทำให้ฟังเป็น AI (สคริปต์เตือนให้อัตโนมัติ)

| ภาษาเขียนแข็ง ๆ | ภาษาพูด |
|---|---|
| ในยุคปัจจุบัน / ในปัจจุบัน | ทุกวันนี้ |
| นอกจากนี้ | อีกอย่างนะ / แล้วก็ |
| อย่างไรก็ตาม | แต่ว่า |
| ทั้งนี้ | (ตัดทิ้ง) |
| เป็นที่ทราบกันดีว่า | หลายคนรู้ว่า |
| สิ่งสำคัญคือ | ที่สำคัญคือ |

- ประโยคสั้น หนึ่งประโยคหนึ่งความคิด ถ้าอ่านรวดเดียวไม่หมดลมหายใจแล้วให้ตัด
- เลี่ยง "ซึ่ง/ที่/ของ" ต่อกันเป็นสายยาว
- ใช้คำลงท้ายเท่าที่เข้ากับโทนของคลิป (ครับ/ค่ะ/นะ) สม่ำเสมอทั้งคลิป อย่าใส่ทุกประโยค

## 2. ทำให้อ่านออกเสียงถูก

- **ตัวเลข** เขียนเป็นคำอ่าน: "7 ชั่วโมง" → "เจ็ดชั่วโมง", "30%" → "สามสิบเปอร์เซ็นต์", ปี พ.ศ. 2569 → "สองพันห้าร้อยหกสิบเก้า"
- **หน่วย** เขียนเป็นคำ: mg → มิลลิกรัม, kg → กิโลกรัม
- **ศัพท์อังกฤษ/ตัวย่อ** ทับศัพท์เป็นไทยตามที่คนออกเสียงจริง: BMI → บีเอ็มไอ, MRI → เอ็มอาร์ไอ
- **เลขอ้างอิง** [1] [2] ไม่ต้องอ่าน (สคริปต์ตัดให้) แต่ถ้าจะอ่านชื่อแหล่งอ้างอิง ให้เขียนเป็นประโยคพูด
- เครื่องหมายที่ไม่ควรอยู่ในบท: bullet, ตัวหนา, วงเล็บอธิบาย, ลูกศร

## 3. จังหวะและน้ำเสียง

- `[หยุดสั้น]` / `[หยุดยาว]` ใส่เฉพาะจุดที่คนพูดจริงจะหยุด (ก่อนตัวเลขสำคัญ, หลังคำถาม hook) สคริปต์แปลงเป็น `<short pause>` / `<long pause>` ให้
- เน้นคำด้วยตัวพิมพ์ใหญ่ใช้ได้กับภาษาอังกฤษเท่านั้น ในไทยให้ใช้การเรียบเรียงประโยคแทน
- style ในสคริปต์สั้นอยู่แล้ว (ห้ามเขียน director's notes ยาว ๆ ใส่ใน style เพราะทำให้เสียงเพี้ยนระหว่างเรื่อง)
- อย่าใส่คำกำกับ เช่น "(พูดช้า ๆ)" ลงในบท เพราะโมเดลจะอ่านออกเสียงคำนั้นด้วย

## 4. ตรวจหลังเจน

ฟังทั้งไฟล์ด้วยหู เช็ก: ชื่อโรค/ศัพท์การแพทย์, ตัวเลข, จังหวะหยุด, เสียงท้ายประโยคลากผิดธรรมชาติ แล้วลบ `scene_XX.wav` เฉพาะฉากที่ไม่ดี รันซ้ำเพื่อเจนใหม่เฉพาะฉากนั้น (ประหยัดโควตา)

## 5. เฉพาะคลิปสุขภาพ/การแพทย์

- ชื่อโรค ยา ศัพท์แพทย์ที่คนทั่วไปไม่คุ้น ให้ทับศัพท์ตามที่คนออกเสียงจริง และอธิบายสั้น ๆ ในประโยคเดียวกัน ฟังรอบแรกให้เช็กคำพวกนี้ก่อนเสมอ
- เล่าผลวิจัยแบบพูด เช่น "งานวิจัยพบว่า…", "ในกลุ่มตัวอย่างประมาณ…คน" ให้ตรงกับชนิดการศึกษาจริง และอย่าใช้คำเกินหลักฐาน เช่น "พิสูจน์แล้ว", "หายขาด", "ป้องกันได้เต็มร้อย"
- ประโยคปิดท้ายแนว "ข้อมูลนี้เพื่อความรู้ทั่วไป ไม่ใช่คำแนะนำทางการแพทย์เฉพาะบุคคล" ให้ใส่ในบทที่จะอ่านจริง ไม่ใช่แค่ในคำอธิบายคลิป
- คำที่มีตัวเลขสำคัญ (เช่น ชั่วโมงการนอน ขนาดกลุ่มตัวอย่าง) ให้ใส่ `[หยุดสั้น]` ก่อนบอกตัวเลข เพื่อให้ผู้ฟังตามทัน
