# ขั้นที่ 8 — ชุดโพสต์: Carousel 2 สไลด์ + แคปชันพร้อมอ้างอิง

ทำหลังขั้น 3 (มีตารางหลักฐานที่ผู้ใช้ยืนยันแล้ว) จะทำก่อนหรือหลังคลิปก็ได้ ไม่ต้องใช้เสียง ไม่เสียโควตา TTS
เนื้อหาทุกตัวเลขต้องมาจากตาราง REFERENCE MAP / SOURCES ของขั้น 3 ห้ามมีตัวเลขที่ไม่อยู่ในนั้น

## ส่งมอบอะไรบ้าง

1. **Carousel 2 สไลด์** (ภาพ PNG): สไลด์ 1 = ความเชื่อผิดตัวใหญ่ + ป้าย "ความเชื่อผิด?"; สไลด์ 2 = ข้อเท็จจริงทางการแพทย์ 3–4 ข้อ + หมายเหตุงานเชิงสังเกต + ข้อความปฏิเสธความรับผิดชอบ
2. **แคปชัน** พร้อมรายการอ้างอิงและแฮชแท็ก (ข้อความ ให้ผู้ใช้ก๊อปไปวาง)
3. **รายการคำที่ปรับเพื่อความถูกต้อง** (บอกผู้ใช้ในแชต ไม่ใส่ในแคปชัน): ถ้าบทหรือคำขอของผู้ใช้ใช้คำที่หลักฐานไม่รองรับ (เช่น "ป้องกัน" จากงานเชิงสังเกต) ให้คงโครงเดิมแต่ลดระดับคำ แล้วบอกว่าแก้อะไรเพราะอะไร

## ทำสไลด์

เขียน `carousel.json` (ข้อความไทยทั้งหมด ไม่ใช้อักขระ ✓ ✗ • ใช้ไอคอนแทน):

```json
{
  "fonts": "kanit-mali",
  "slide1": {"headline": "กินถั่วเหลืองแล้วเสี่ยงมะเร็งเต้านม?", "badge": "ความเชื่อผิด?", "icon": "cross"},
  "slide2": {
    "title": "ข้อเท็จจริงทางการแพทย์",
    "points": ["ข้อที่ 1 (ตรงกับ Fact Card ในคลิป)", "ข้อที่ 2", "ข้อที่ 3"],
    "note": "งานวิจัยเชิงสังเกตบอกความสัมพันธ์ ไม่ได้พิสูจน์สาเหตุ",
    "icon": "check"
  }
}
```

- `headline` ≤ ~40 ตัวอักษร (ระบบตัดบรรทัดตามคำไทยและย่อฟอนต์ให้พอดี ไม่เกิน 4 บรรทัด); `points` 2–5 ข้อ แนะนำ 3–4 ข้อ ข้อละ ≤ ~60 ตัวอักษร
- `note`: ค่าเริ่มต้นคือหมายเหตุงานเชิงสังเกต ใส่ `false` ถ้าหลักฐานเป็นการทดลองแบบสุ่ม; `footer` ของสไลด์ 2 มีข้อความปฏิเสธความรับผิดชอบเป็นค่าเริ่มต้น
- `icon` ต้องเป็น prop ที่มี (`cross`, `check`, `heart`, `shield` ฯลฯ ดู `video-pipeline.md`)

```bash
S=~/.claude/skills/health-clip-thai/scripts   # หรือ path ใต้ ~/.claude/plugins/cache/
R="uv run --with pycairo --with numpy --with pillow --with pythainlp python"
$R $S/make_video.py carousel carousel.json --out out/ --name clip --aspect 4:5   # 4:5 (ค่าเริ่มต้น) | 1:1 (รองรับเฉพาะสองสัดส่วนนี้ เพราะเป็นสัดส่วนโพสต์ฟีด)
```

ผลลัพธ์: `out/clip_slide1_4x5.png`, `out/clip_slide2_4x5.png` ข้อความไทยผ่าน ASS + libass เหมือนวิดีโอ (cairo ไม่วาดตัวอักษร) แล้วดึงภาพนิ่งด้วย `ffmpeg-skill` `look --at` จึงต้องมี `ffmpeg-skill` เช่นเดียวกับขั้น 7

**ตรวจก่อนส่งมอบ:** เปิดไฟล์ PNG ทั้งสองด้วยตา เช็กว่าสระ/วรรณยุกต์ไทยซ้อนถูก ไม่มีสี่เหลี่ยม ข้อความไม่ล้นการ์ด และตัวเลขตรงกับตารางหลักฐาน

```

สรุปจากหลักฐาน:
- [ข้อ 1 พร้อมตัวเลขจากงานที่ [1]]
- [ข้อ 2 [2]]
- [ข้อ 3 [3]]
(ข้อความเหล่านี้เป็นการสังเกตความสัมพันธ์ ไม่ใช่การพิสูจน์เหตุและผล  <- ใส่เมื่อเป็นงานเชิงสังเกต)

[1-2 บรรทัด: ทำอย่างไรต่อ แยกอาหารปกติกับอาหารเสริม; ผู้ป่วยที่กำลังรักษาให้ถามแพทย์ผู้ดูแล]

อ้างอิง:
[1] ผู้แต่ง. ชื่อเรื่อง. วารสาร ปี. PMID: 00000000. DOI/ลิงก์
[2] ...

```

## กฎ (ห้ามพลาด)

- ทุกการอ้างอิงต้องเป็นงานที่เปิดอ่านได้จริงในขั้น 2 ลงชื่อผู้แต่ง วารสาร ปี และ PMID ห้ามสร้าง PMID/DOI/ลิงก์ขึ้นเอง และตัวเลขต้องตรงกับ abstract
- งานเชิงสังเกต = "พบว่าคนที่…มีความเสี่ยงต่ำกว่า / สัมพันธ์กับ" ห้าม "ป้องกัน / รักษาหาย / ปกป้อง" งานทดลองแบบสุ่มใช้ "ลดลง" ได้ ต้องมีหมายเหตุงานเชิงสังเกตเมื่อใช้งานสังเกต
- กลไกใช้ "จับได้ยากขึ้น" ไม่ใช่ "จับไม่ได้" เว้นแต่หลักฐานแรงขนาดนั้น
- แยกอาหารปกติออกจากอาหารเสริมเข้มข้น และแนะนำให้ผู้ป่วยระหว่างรักษาถามแพทย์
- แคปชันต้องจบด้วยประโยคปฏิเสธความรับผิดชอบทางการแพทย์ และเลขอ้างอิงในแคปชันต้องตรงกับ REFERENCE MAP ในบท
- ไม่ใส่ข้อความอ้างอิงบนการ์ดโลโก้ท้ายคลิป เว้นแต่ผู้ใช้ขอ
- ภาพไม่มีตัวละครมีลิขสิทธิ์ และห้ามคัดลอกโลโก้ผู้ใช้เข้า repo (สไลด์นี้ไม่ใช้โลโก้)
